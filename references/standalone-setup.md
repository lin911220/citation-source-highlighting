# 安裝與常見問題

第一次使用，先照 [README 的三個步驟](../README.md)操作。本頁補充環境準備與常見疑問。

## 需要準備什麼？

- 能讀取本機檔案、執行 Python 的 AI 工具。
- Python 3.10 以上，以及處理 PDF 的 PyMuPDF 套件。
- 你的論文 .tex、書目 .bib，以及被引用文章的 PDF 全文。

使用 Git clone 時也需要 Git。這是一個可單獨使用的 skill。

## Python 或套件還沒準備好怎麼辦？

先對 AI 說：

> 請先檢查執行這個 skill 需要的 Python 與 PDF 套件，協助我完成必要的環境準備，再開始核對。

如果你習慣自己執行指令，在論文資料夾內安裝依賴：

```sh
python -m pip install -r citation-source-highlighting/scripts/requirements.txt
```

## 參考文獻究竟放哪裡？

把全文 PDF 放在 **你的論文資料夾／參考論文／**，把書目檔 references.bib 放在論文資料夾內。[README](../README.md) 有完整擺放範例。

書目檔記錄作者、標題、年份等資料；畫螢光筆還需要文章的 PDF。PDF 檔名可以尚未整理，AI 會先讀取標題、作者與版本來核對身分。

如果 PDF 已放在其他地方，告訴 AI 完整路徑即可。直接修改來源 PDF 時，檔案必須位於選定的論文專案內，因此可以先複製進來；專案外的 PDF 則可供讀取並產生標註副本。

## 論文有分章節、檔名也不同，可以使用嗎？

可以。告訴 AI 哪個是主檔、哪個是書目檔、參考 PDF 放在哪裡。程式會沿著主檔的 input/include 讀取章節。

## 一定要把 skill 安裝到 AI 工具的專用目錄嗎？

在論文資料夾放入整個 skill，請 AI 先讀取其中的 SKILL.md，就可以依照指引工作。也可以依所用工具的方式安裝到 skills 目錄；保留資料夾內各檔案的相對位置即可。

## 核對完成後，檔案放哪裡？

如果需求是「直接在來源 PDF 標註」，就開啟原本的參考 PDF 查看。若要保留原檔，可以對 AI 說「請另外產生標註副本」。

預設採另存副本的方式；副本與執行報告放在論文資料夾的 annotated_papers/run-*。引用依據另記錄在 citation_evidence.json，由 AI 在工作時建立與更新。

## 能處理 Word 或掃描的 PDF 嗎？

目前程式掃描 LaTeX／BibTeX。Word 需要另外整理引用位置，掃描版 PDF 需要另行 OCR；無法直接套用相同掃描流程。

## 標註後是否就表示引用一定正確？

顏色反映 AI 閱讀後對支持關係的判定；你可以點選標註回看原文與原因。程式會確認文字位置與存檔，但文字找到、引用合適和整篇文章已讀完，是不同的檢查。

每次新增或改寫引用後，再請 AI 核對受影響的部分。這個 skill 沒有背景監控功能。

命令列與測試方法見 [進階操作](evidence-ledger.md)。
