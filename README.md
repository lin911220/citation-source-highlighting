# 幫你的參考論文畫出引用原文

你在自己的論文引用了一篇文章，想回頭確認「我引用的內容，原文到底在哪裡？」

**這個 skill 讓 AI 幫你找到那段原文，並直接在參考論文的 PDF 畫上螢光筆。** 點選標註，就能看到你的論文在哪裡引用它，以及核對說明。

例如：你的論文寫「A 方法使用多尺度特徵」，並引用 A 論文 → AI 讀取 A 的 PDF、核對這個說法 → 在支持它的原句畫線；若內容不吻合，就列出差異。

目前適用於 **LaTeX 論文（.tex）、BibTeX 書目（.bib）及參考文獻 PDF**。搭配能讀取本機檔案、執行 Python 的 AI 工具使用。

## 第一次使用，只要照這三步

### 1. 準備你的論文與參考 PDF

把引用到的論文 PDF 放進「參考論文」資料夾：

```text
我的論文/
├── thesis.tex           ← 你正在寫的論文
├── references.bib       ← 你的書目資料
└── 參考論文/
    ├── 論文 A.pdf       ← 被你引用的文章全文
    └── 論文 B.pdf
```

檔名可以不同，PDF 檔名尚未整理也可以。**要準備 PDF 全文，只有書目資料還無法畫出原文。**

### 2. 把這個 skill 放進論文資料夾

在「我的論文」資料夾裡執行：

```sh
git clone https://github.com/lin911220/citation-source-highlighting.git
```

完成後，論文資料夾裡會多一個 `citation-source-highlighting` 資料夾。整個 skill 都在裡面。

### 3. 在 AI 工具中開啟論文資料夾，貼上這段話

```text
請先讀取 citation-source-highlighting/SKILL.md，依照指引幫我核對論文引用。
我的論文主檔是 thesis.tex，書目檔是 references.bib，
參考 PDF 都放在「參考論文」資料夾。
請逐筆核對引用，直接在來源 PDF 標出支持的原文，
並列出找不到原文或引用內容不吻合的地方。
```

把範例檔名換成自己的即可。AI 會先確認檔案與執行環境，再閱讀原文並產生標註。

## 完成後，你會看到什麼？

打開參考 PDF，就能看到引用原文的螢光筆：

| 顏色 | 代表什麼 |
| --- | --- |
| 黃色 | 這段原文支持你的引用內容 |
| 橘色 | 只支持一部分，有內容需要釐清 |
| 紫色 | 這是你的推論，原文沒有直接提出同樣的結論 |

點選標註可查看對應的論文位置與原因。找不到原文的引用會另外列出。同段原文被引用多次時，會共用標註。
